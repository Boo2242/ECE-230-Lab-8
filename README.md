## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer allows you to choose one signal to output from a number of given inputs. Multiplexers
are controlled with select inputs. An example would be a 2:1 mux which would require one select to choose between 2 inputs. 
A 4:1 mux would need 2 selects.

### In plain English describe the function and use of a demultiplexer.
A demultiplexer is the inverse of multiplexer, taking a single input signal and routing it to a number of outputs
using the same select system. It functions identically to a mux just in reverse.

### What other uses might these circuits have? (Think Shannon’s)
Mux's and demux's can be used for many circuits, an example would be selecting between audio inputs
into a single audio output.
